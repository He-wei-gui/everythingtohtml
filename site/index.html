everythingtohtml

Convert (almost) any file — PDF, Word, Excel, PowerPoint, Markdown, CSV, JSON and more — into clean, self-contained HTML. For humans and for LLMs.

★ Star on GitHub Read the docs
pip install "everythingtohtml[all]"

Why HTML instead of Markdown?

Markdown is lossy — tables flatten, structure vanishes, slides collapse. everythingtohtml is the structural inverse of markitdown: it lifts documents up into HTML that keeps the structure that matters.

🧑‍💻 Human-friendly

Open the output in any browser — no toolchain, dark-mode aware, restyleable.

🤖 Model-friendly

Explicit <table> / <section> structure that LLMs parse reliably for RAG and document QA.

📦 Self-contained

One valid HTML5 file per document, with a small embedded stylesheet.

🔌 Pluggable

A tiny converter contract and entry-point plugins — add a format in one small class.

Supported formats

.pdf.docx.doc .xlsx.pptx.epub .md.html.csv .tsv.json.jsonl .ipynb.rss.atom .eml.odt .yaml.rst.txt

Use it in five seconds

# Python
from everythingtohtml import EverythingToHtml

eth = EverythingToHtml()
result = eth.convert("quarterly-report.docx")
open("report.html", "w").write(result.html)

# Merge a stack of Word docs — or diff two revisions
eth.merge(["intro.docx", "chapter1.doc", "appendix.pdf"])
eth.diff("spec-old.docx", "spec-new.docx")
# Command line
everythingtohtml report.docx -o report.html
everythingtohtml old.docx new.docx --diff -o changes.html
cat notes.md | everythingtohtml --extension .md > notes.html
